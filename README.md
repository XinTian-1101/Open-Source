## Abstract

The Open Source repository serves as a collection of web development tutorials and assignments, each maintained in separate branches focusing on different technologies and topics.

## Branch Overview

### `tutorial2`
A responsive one-page personal portfolio website built using React. It includes:
- An introduction
- Image
- Table
- Embedded video

This branch demonstrates basic React concepts and responsive design techniques.

### `tutorial4`
A simple, responsive homepage created with **Bootstrap**, focusing on layout and design fundamentals using the Bootstrap framework.

### `tutorial5_php`
A **PHP-based** branch that explores foundational PHP logic and scripting, such as:
- Handling form inputs
- Simple calculation logic
- Printing dynamic content

### `FutureEarth-Assignment1`
An individual project aimed at raising awareness about **climate change**. Built using **HTML, CSS, Bootstrap, and PHP (without a database)**, it includes:
- A homepage
- Educational content
- A topic-based quiz
- A carbon footprint calculator
- A news section that fetches real-time environmental updates via a news API

## Purpose

This repository is designed to showcase learning progress and experimentation with different:
- Technologies
- Frameworks
- Programming paradigms

across various web development topics.
