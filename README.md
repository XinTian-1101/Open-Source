Abstract

The Open Source repository serves as a collection of web development tutorials and assignments, each maintained in separate branches focusing on different technologies and topics.

Each branch highlights a specific learning objective or project:

tutorial2: A responsive one-page personal portfolio website built using React. It includes an introduction, an image, and an embedded video, demonstrating basic React concepts and responsive design techniques.

tutorial4: A simple, responsive homepage created with Bootstrap, focusing on layout and design fundamentals using the Bootstrap framework.

tutorial5_php: A PHP-based branch that explores foundational PHP logic and scripting, such as handling form inputs and printing dynamic content.

FutureEarth-Assignment1: An individual project aimed at raising awareness about climate change. This site is built using HTML, CSS, Bootstrap, and PHP (without a database). It features a homepage, educational content, a topic-based quiz, a carbon footprint calculator, and a news section that fetches real-time environmental updates via a news API.

This repository is designed to showcase learning progress and experimentation with different technologies, frameworks, and programming paradigms across various web development topics.
